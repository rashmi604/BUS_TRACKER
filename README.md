# BusKr - Smart Bus Tracker

A real-time bus tracking system built with React and Leaflet.

## Features
- Real-time bus location tracking
- Interactive map visualization
- Route management
- User-friendly interface

## Tech Stack
- React 18.3.1
- Vite
- Leaflet for mapping
- React Leaflet

## Getting Started
```bash
npm install
npm run dev
```
